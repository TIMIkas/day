ДЕНЬ ЗА ДНЁМ — ANDROID-ПРИЛОЖЕНИЕ
Версия 1.1

ЭТО УЖЕ НЕ САЙТ ДЛЯ ОТКРЫТИЯ В БРАУЗЕРЕ
Проект содержит Android-приложение. После сборки APK оно устанавливается на телефон как обычная программа, имеет свою иконку, запускается отдельно и работает офлайн. Интерфейс работает внутри встроенного Android WebView; адресной строки и браузерного интерфейса нет.

СБОРКА APK (нужен компьютер с Android Studio)
1. Установи Android Studio с официального сайта: https://developer.android.com/studio
2. Распакуй архив DenZaDnyom-Android.zip.
3. В Android Studio выбери Open и укажи папку DenZaDnyom-Android.
4. Дождись синхронизации Gradle. Если Android Studio предложит установить Android SDK Platform 35 и Build Tools — согласись.
5. В меню Build выбери Build Bundle(s) / APK(s) → Build APK(s).
6. После сборки нажми locate. APK будет в app/build/outputs/apk/debug/app-debug.apk.
7. Перенеси APK на телефон и установи. Android может попросить разрешить установку из выбранного файлового менеджера.

ВОЗМОЖНОСТИ
- Календарь и дневник по дням.
- Вода, экранное время, учёба и активность.
- Сон: время начала/окончания и длительность.
- Субъективные оценки сна, настроения, энергии, концентрации и мотивации.
- Привычки, питание, заметки, оценка дня.
- Пользовательские поля: число, счётчик, оценка 1–10, да/нет, заметка, временной интервал.
- Статистика за 7/30/90 дней.
- Резервное копирование и восстановление через системный выбор файлов Android.
- Данные хранятся локально на устройстве; сервер/аккаунт не нужен.

ВАЖНО
- Автоматической синхронизации с другими устройствами пока нет. Для переноса используй экспорт JSON на одном устройстве и импорт на другом.
- APK в этом архиве не приложен: в среде создания не установлен Android SDK/Gradle, поэтому я не могу честно заявить, что собрал и проверил установочный APK на эмуляторе. Исходный Android Studio-проект готов к сборке.
- Проверки, выполненные перед передачей: синтаксис JavaScript (node --check), базовая проверка HTML и статическая проверка Android-манифеста/структуры проекта. Реальный запуск на телефоне ещё требуется.

ТЕСТИРОВАНИЕ
После установки проверь: создание записи; переход между датами; добавление привычки и пользовательского показателя; перезапуск приложения и сохранение записей; экспорт JSON; очистку тестовых данных и импорт JSON обратно.

АЛЬТЕРНАТИВА: ПОЛУЧИТЬ APK ЧЕРЕЗ GITHUB ACTIONS
В архив добавлен workflow .github/workflows/build-apk.yml.
1. Создай пустой репозиторий на GitHub.
2. Загрузи туда всё содержимое папки DenZaDnyom-Android (включая скрытую папку .github).
3. Открой вкладку Actions и дождись завершения задания Build Android APK.
4. В завершившемся запуске скачай артефакт den-za-dnyom-debug-apk — внутри будет app-debug.apk.
5. Установи APK на Android.
Это debug-сборка для личной установки, не публикационная подписанная версия Google Play.
